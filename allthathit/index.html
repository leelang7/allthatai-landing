AllThatHit 사용 안내

갤럭시 워치(Wear OS 4 이상)에서 쭈꾸미·갑오징어를 세는 앱입니다. 폰 앱은 없습니다.

시작세기출조 시작·끝질문 기록순위백업·복원구독자주 묻는 것

1. 처음 켜면

  1. 권한 3개를 허용합니다. 위치(포인트 기록·날씨), 마이크(말로 세기), 알림(출조 중 마릿수 표시).
  2. 큰 숫자가 보이면 끝입니다. 이 화면이 계수기입니다.
  3. 위쪽 띠 메뉴 · 출조 시작을 누르고 출조 시작을 누르면 출조가 열립니다.

워치 설정 → 계정 및 백업 → 백업이 켜져 있으면, 구글 계정으로 기록이 자동 백업됩니다(7번).

2. 세는 법

할 일방법
한 마리화면 아무데나 탭. 또는 오른쪽 +
잘못 셌을 때왼쪽 −. 또는 "취소"라고 말하기
갑오징어로 바꾸기아래 갑오징어 칩을 탭. 다시 탭하면 쭈꾸미
말로 세기마이크 단추 → "쭈꾸미 두 마리", "갑오징어 하나", "두 마리 빼"
출조 끝내기메뉴 → 출조 종료. 안 눌러도 저절로 끝납니다(3번)

0.6초 안에 두 번 눌리면 한 번으로 셉니다. 젖은 장갑으로 눌러도 됩니다.

3. 출조 시작과 끝

시작: 위쪽 띠 → 출조 시작. 깜빡하고 화면을 먼저 탭하면 "출조를 시작하고 이 한 마리를 셀까요?"라고 묻습니다 — 네를 누르면 시작과 함께 한 마리가 세어집니다.

끝: 메뉴 → 출조 종료. 안 눌러도 아래 중 하나면 저절로 끝납니다.

  • 워치를 충전기에 올림 (2분 뒤)
  • 워치를 손목에서 풂 (10분 뒤)
  • 고패질도 마릿수도 한 시간 동안 없음

끝난 시각은 마지막으로 낚시한 때로 적힙니다. 한 마리도 세지 않고 저절로 끝난 출조는 기록에 남기지 않습니다.

출조를 시작하지 않으면 앱은 센서를 켜지 않고 배터리도 쓰지 않습니다.

  • 메뉴 → 자동 감지 켜기(처음에는 꺼져 있음): 켜면 고패질 리듬이 4분 이어질 때 출조가 저절로 열립니다. 켜 둔 동안은 출조가 아닐 때도 동작 센서를 낮은 빈도로 봅니다.
  • 메뉴 → 내 고패질 재기: 30초 동안 평소대로 흔들면 내 리듬을 잽니다. 자동 감지를 쓸 때만 필요합니다.

4. 물어보면 답합니다

메뉴 → 지금 어때?, 또는 마이크 단추로 말하기. 답은 손목에 글로 뜨고 소리로도 읽어 줍니다(메뉴 → 소리 끄기).

"오늘 몇 물이야" · "바람 세져?" · "해 언제 져" · "수온 몇 도야" · "지금 몇 마리야" · "지난주엔 몇 마리 했지"

물때는 서해 7물때식, 바람·수온·파고는 지금 있는 자리의 예보입니다. 인터넷이 없으면 워치가 아는 것으로만 답합니다(마릿수·시간당). 출조 중 20분마다 코칭 한 줄이 옵니다(메뉴 → 코칭 끄기).

기록은 워치 안에만 있습니다. 좌표는 서버로 나가지 않습니다.

6. 순위 (원할 때만)

메뉴 → 순위 → 참여하기. 나가는 것은 별명(앱이 붙임)·마릿수·1km 단위 구역·날짜·검증 점수뿐입니다. 정확한 자리는 나가지 않습니다.

  • 동작 센서가 챔질을 확인한 비율이 60%를 넘는 출조만 순위에 듭니다. 집에서 누른 숫자는 들지 못합니다.
  • 구역 순위는 이틀 뒤, 세 명 이상 다녀간 곳만 보입니다.
  • 참여 그만두기를 누르면 올린 기록이 전부 지워집니다.

7. 백업과 복원

워치를 바꿔도 기록이 남게 두 가지가 있습니다.

  1. 구글 계정 백업 — 워치 설정의 백업이 켜져 있으면 충전 중·Wi-Fi 연결 시 하루 한 번 구글 드라이브에 저장됩니다. 같은 계정의 새 워치에 앱을 깔면 돌아옵니다.
  2. 백업 코드 — 메뉴 → 개인정보 → 기록 백업에 12자 코드가 있습니다. 출조가 끝날 때마다 기록이 이 코드로 잠겨 서버에 올라갑니다. 새 워치에서 메뉴 → 개인정보 → 기록 복원에 코드를 치면 마릿수·포인트·배운 것이 돌아옵니다.
코드는 사진으로 찍어 두세요. 코드는 워치에만 있고 서버는 내용을 읽을 수 없어서, 코드를 잃으면 사본도 되찾을 수 없습니다.

8. 코칭 구독

계수·기록·내 포인트·순위는 무료이고 앞으로도 무료입니다. 파는 것은 코칭(자동 코칭과 질문)뿐입니다.

메뉴 → 코칭 구독. 결제와 해지는 구글 플레이가 맡습니다(플레이 스토어 → 정기 결제). 해지해도 남은 기간은 그대로 쓸 수 있습니다.

9. 개인정보

회원가입·로그인·광고가 없습니다. 무엇이 워치에 남고 무엇이 나가는지는 개인정보처리방침에 그대로 적혀 있습니다. 메뉴 → 개인정보 → 전부 지우기로 워치와 서버의 기록을 지울 수 있습니다.

10. 자주 묻는 것

출조가 저절로 켜졌는데 낚시가 아니었어요. 자동 감지를 켠 경우에만 생깁니다. 알림의 낚시 아님을 누르면 그 출조가 지워지고 그 자리에서는 다시 켜지지 않습니다. 메뉴 → 자동 감지 끄기로 아예 끌 수 있습니다.

마릿수 화면이 안 보여요. 뒤로 가기(오른쪽에서 왼쪽으로 쓸기)나 메뉴 → 뒤로. 출조 중에는 알림에서도 +1·−가 됩니다.

코칭이 답을 안 해요. 인터넷이 없거나 서버가 잠깐 쉬는 때입니다. 계수는 영향이 없습니다. 메뉴 → 상태에서 네트워크와 코칭 상태가 보입니다.

배터리를 얼마나 쓰나요. 출조를 시작하지 않으면 쓰지 않습니다. 출조 중에는 GPS와 동작 센서가 켜집니다. 자동 감지를 켠 경우에만 출조가 아닐 때도 가속도 센서를 낮은 빈도로 봅니다.
